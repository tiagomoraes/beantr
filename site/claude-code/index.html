Install

Track your coffee in Claude Code.

A Claude Code plugin. No clone, no shell: add the marketplace, install the plugin, and Claude Code keeps your notes.

Paste this to Claude Code

Install the Beantr plugin so you can keep track of my coffee: run /plugin marketplace add tiagomoraes/beantr, then /plugin install beantr@beantr. Then set up my coffee notes at ~/beantr and tell me you are ready.

Or run it yourself

/plugin marketplace add tiagomoraes/beantr
/plugin install beantr@beantr

What that does.

  1. 1

    Register the marketplace.

    /plugin marketplace add tiagomoraes/beantr tells Claude Code this repository is a plugin marketplace.

  2. 2

    Install the plugin.

    /plugin install beantr@beantr. Claude Code loads the skill on its own whenever you talk about coffee.

  3. 3

    Then just ask.

    Claude Code creates and updates your notes at ~/beantr as you go.

  4. 4

    No plugin support?

    Run curl -fsSL https://beantr.tiagomoraes.cloud/install | bash -s -- claude-code instead. It copies the skill into ~/.claude/skills and adds a short reminder of the notes folder to ~/.claude/CLAUDE.md.

Then just talk about coffee.

  • What should I brew this morning?
  • Log this espresso: 18g in, 42g out, 31 seconds, a bit sour.
  • What's left on the shelf?
  • What worked best this month?

For the AI agent reading this page

If you are Claude Code, or another agent, reading this for someone: install the plugin with /plugin marketplace add tiagomoraes/beantr then /plugin install beantr@beantr.

If you cannot run plugin commands, run curl -fsSL https://beantr.tiagomoraes.cloud/install | bash -s -- claude-code instead. Then create their coffee notes at ~/beantr from the skill's templates and ask what beans they have.
