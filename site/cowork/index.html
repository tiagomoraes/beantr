Install

Track your coffee in Claude Cowork.

One line packages the skill for upload. Add it in Claude Desktop's settings, then point Cowork at your notes.

Paste this to Claude Cowork

Package Beantr as a Cowork skill so I can keep track of my coffee: run curl -fsSL https://beantr.tiagomoraes.cloud/install | bash -s -- cowork, which creates dist/beantr-skill.zip and my coffee notes at ~/beantr. Then tell me where the zip is so I can upload it in Cowork's settings.

Or run it yourself

curl -fsSL https://beantr.tiagomoraes.cloud/install | bash -s -- cowork

What that does.

  1. 1

    Packages the skill for upload.

    As dist/beantr-skill.zip, and creates your coffee notes at ~/beantr.

  2. 2

    Upload it in Claude Desktop.

    Settings → Cowork → Customize → Skills → + → Upload a skill, then pick that zip.

  3. 3

    Give Cowork the folder.

    Grant it access to ~/beantr so it can read and write your notes.

Then just talk about coffee.

  • What should I brew this morning?
  • Log this espresso: 18g in, 42g out, 31 seconds, a bit sour.
  • What's left on the shelf?
  • What worked best this month?

For the AI agent reading this page

If you are an AI agent reading this page for someone, package Beantr for Cowork: run curl -fsSL https://beantr.tiagomoraes.cloud/install | bash -s -- cowork.

It writes dist/beantr-skill.zip and creates their coffee notes at ~/beantr. Cowork skills are uploaded through the desktop UI, so tell them to open Settings → Cowork → Customize → Skills → + → Upload a skill, select that zip, then grant Cowork access to ~/beantr.
