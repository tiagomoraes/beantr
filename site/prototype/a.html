The ledger Rules GitHub

A coffee ledger your agent keeps.

A skill, not an app. One command teaches your agent to track beans, gear, recipes and brews in Markdown.

curl -fsSL https://beantr.tiagomoraes.cloud/install | bash -s -- all

Inside Claude Code you can also install it as a plugin: /plugin marketplace add tiagomoraes/beantr then /plugin install beantr@beantr.

Creates the skill for each agent on this machine and a ledger at ~/beantr.

Live state / what is true right now

Every current.md is edited in place: beans on the shelf, gear in use, the recipe you would reach for today.

Evidence / what actually happened

History and session files are append-only. Every brew, restock and correction is kept, never rewritten.

Distilled / what to do next

insights/current.md changes only when the evidence is strong enough to be useful. No generic theory.

Five things Beantr will not compromise on.

The filesystem is the API.

Agents use ordinary file tools. No HTTP calls, no MCP server, no database credentials, no account.

Current state beats inferred state.

A current.md answers what is true now. The agent never replays history to find out.

Logs stay append-only.

History is evidence, not mutable state. Session and history files only ever grow.

Recommendations cite evidence.

Good advice points to recent sessions or stable preferences, never to generic theory.

Humans can always edit the files.

No special UI required. Open any file, in any editor, at any time.
