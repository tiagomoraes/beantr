Coffee, kept by your agent, in plain files.

A skill for Claude Code, Hermes, OpenCode, OpenClaw and Cowork. Your ledger is a folder of Markdown at ~/beantr.

What it is
A skill
One SKILL.md your agent loads. It says what goes in which file, what each field means, and when to write.
A folder
Eight Markdown files. Beans, gear, recipes, sessions, insights. Open them in any editor, sync them however you like.
No server
No API, no database, no account. The agent uses the file tools it already has.
Install

One line, any agent

The command in the left column downloads the pack and installs the skill for the agent you name. Run it with no name to see which agents it detects. Nothing is installed until you pick one.

Rules
  1. 1

    The filesystem is the API.

    Agents use ordinary file tools. No HTTP calls, no MCP server, no database credentials, no account.

  2. 2

    Current state beats inferred state.

    A current.md answers what is true now. The agent never replays history to find out.

  3. 3

    Logs stay append-only.

    History is evidence, not mutable state. Session and history files only ever grow.

  4. 4

    Recommendations cite evidence.

    Good advice points to recent sessions or stable preferences, never to generic theory.

  5. 5

    Humans can always edit the files.

    No special UI required. Open any file, in any editor, at any time.
